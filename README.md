# MAXX music player(ALX Capstone Project)


Project Overview
This is my ALX Front-End Development Capstone Project for the program.
The goal is to build a Music Player application using React, JavaScript, HTML, CSS (with optional TailwindCSS), and the Deezer API.

Users can:

Search for tracks by title, artist.
View search results with track details.
Previews of tracks.
Use basic playback controls (play, pause, skip).
Enjoy a responsive layout


Resources

React (Vite) – frontend framework
Tailwind CSS (optional) – styling
Deezer API – fetch music data
GitHub + Git – version control
Vercel/Netlify – deployment
